# docs 구조 안내

이 폴더는 `mouse-ui`의 제품 방향, 개발 흐름, 작업 규칙을 정리한다.

버전별로만 의미가 있는 문서는 각 버전 폴더에 두고, 여러 버전에서 함께 쓰는 운영 규칙은 `docs/` 최상위에 둔다.

## 버전 문서

- [v0 문서 안내](v0/README.md): `v0.5.0`까지의 초기 MVP 기획, 규칙, 체크리스트, 작업 기록
- [v1 문서 안내](v1/README.md): v1 목표, 기능 우선순위, 데이터 규칙, 파일 구조 기준

## 공통 운영 문서

- [작업 흐름 설명서](workflow.md): 앞으로 작업을 어떻게 진행할지 정리한 운영 기준
- [변경 기록](change_log.md): 프로젝트 방향이나 기준이 바뀐 큰 결정을 기록
- [커밋 규칙](commit_convention.md): 기능 단위 커밋 메시지 기준
- [PR 작성 규칙](pr_convention.md): PR을 만들 때 제목과 본문을 쓰는 기준

## 현재 문서 운영 방식

- 기능 하나를 만들 때마다 모든 문서를 갱신하지 않는다.
- 기능 커밋과 문서 커밋은 분리한다.
- 버전이나 큰 작업 묶음이 끝날 때 README와 docs 상태를 확인한다.
- 버전 전용 기준은 해당 버전 폴더에 정리하고, 공통 기준은 최상위 문서에 정리한다.

## 현재 방향

`v0.5.0`까지의 작업은 프로젝트의 첫 저장 가능한 기준점으로 `docs/v0/`에 보관한다.

현재 구현과 사용성 개선은 [v1 문서](v1/README.md)를 기준으로 진행한다.
