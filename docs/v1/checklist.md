# v1 체크리스트

이 문서는 v1 계열 UI 빌더 구현 상태를 기능 단위로 확인하기 위한 체크리스트다.

## 1. v1 기본 구현

- [x] 화면 크기 프리셋을 제공한다.
- [x] 커스텀 캔버스 크기를 입력할 수 있다.
- [x] 캔버스 확대/축소와 이동 상태를 저장한다.
- [x] 마우스 휠로 확대/축소한다.
- [x] 마우스 휠은 작업 중인 중앙 캔버스를 스크롤하지 않고 확대/축소한다.
- [x] 좌우 작업 영역은 자체 스크롤이 가능하다.
- [x] 컨테이너 안에 요소를 넣을 수 있다.
- [x] 컨테이너 이동 시 내부 요소가 함께 이동한다.
- [x] JSON 내보내기와 불러오기를 지원한다.
- [x] 생성 HTML이 현재 project 데이터와 일치한다.

## 2. v1.2 사용성 개선

- [x] Space를 누른 상태에서 마우스를 움직이면 캔버스를 이동할 수 있다.
- [x] 객체 우클릭 메뉴에서 삭제할 수 있다.
- [x] 빈 캔버스 드래그로 여러 객체를 선택할 수 있다.
- [x] 여러 선택 객체 중 하나를 드래그하면 함께 이동한다.
- [x] 선택 객체는 캔버스에서 강조 표시된다.
- [x] 선택 객체는 HTML 코드 패널에서도 강조 표시된다.
- [x] 캔버스 모서리 둥글기와 외곽 border를 제거했다.

## 3. v1.3 컨테이너 구조

- [x] 툴바에서 박스 추가 기능을 제거했다.
- [x] 기존 저장 데이터의 `box` 타입을 불러올 때 `container`로 변환한다.
- [x] 컨테이너 우클릭 메뉴에서 컨테이너를 추가할 수 있다.
- [x] 컨테이너 안에 버튼, 텍스트, input, 이미지, 컨테이너를 추가할 수 있다.
- [x] 컨테이너 안에 컨테이너를 중첩해서 넣을 수 있다.
- [x] 컨테이너 내부 요소를 움직일 때 부모 컨테이너가 같이 움직이지 않는다.
- [x] HTML 생성 결과가 중첩된 `<div>` 구조로 출력된다.

## 4. v1.3 애니메이션 미리보기

- [x] hover 애니메이션을 캔버스에서 미리볼 수 있다.
- [x] click 애니메이션을 캔버스에서 미리볼 수 있다.
- [x] 페이지 진입 애니메이션을 재생 버튼으로 확인할 수 있다.
- [x] 상태 변경 애니메이션을 토글로 확인할 수 있다.
- [x] 드래그/리사이즈 중에는 편집 동작이 우선한다.

## 5. v1.3 도킹 작업 패널

- [x] 오른쪽 고정 사이드바를 도킹 작업 패널로 전환했다.
- [x] 작업 패널은 조정, 꾸미기, 애니메이션, HTML 탭으로 구성된다.
- [x] 작업 패널은 화면에서 떼어 드래그 이동할 수 있다.
- [x] 작업 패널은 크기를 조절할 수 있다.
- [x] 작업 패널은 다시 오른쪽에 붙일 수 있다.
- [x] 작업 패널은 레이아웃 초기화가 가능하다.
- [x] 작업 패널 위치, 크기, 열린 탭, 도킹 여부는 project JSON과 분리해 workspace settings에 저장한다.

## 6. v1.3 꾸미기 확장

- [x] 꾸미기 탭에서 배경색과 글자색을 조정할 수 있다.
- [x] 선형 그라데이션의 방향, 시작 색상, 끝 색상을 조정할 수 있다.
- [x] 그라데이션 시작/끝 기준점을 조정할 수 있다.
- [x] 투명도를 조정할 수 있다.
- [x] 그림자 사용 여부, x, y, blur, spread, 색상, 투명도를 조정할 수 있다.
- [x] border 사용 여부, 색상, 두께, 스타일을 조정할 수 있다.
- [x] 모서리 둥글기를 조정할 수 있다.
- [x] 저장/불러오기 후에도 v1.3 스타일 설정이 유지된다.
- [x] HTML 생성 결과에 그라데이션 기준점, 그림자, border, 투명도가 반영된다.

## 7. v1.3 완료 기준

- [x] 박스 없이 컨테이너만으로 영역을 만들 수 있다.
- [x] 컨테이너 안에 컨테이너를 넣을 수 있다.
- [x] 기존 box 데이터가 container로 안전하게 변환된다.
- [x] 애니메이션을 캔버스에서 확인할 수 있다.
- [x] 작업 패널을 탭으로 사용할 수 있다.
- [x] 작업 패널을 원하는 위치로 이동할 수 있다.
- [x] 꾸미기 탭에서 그라데이션, 그림자, border, 모서리를 조정할 수 있다.
- [x] 그라데이션 시작/끝 기준점을 조정할 수 있다.
- [x] 저장/불러오기 후에도 설정이 유지된다.

## 8. v1.3.1 버그 수정

- [x] 컨테이너 안에 생성한 컴포넌트를 이동할 수 있다.
- [x] 작업 패널에서 떼기 버튼을 누르면 패널을 자유롭게 이동할 수 있다.
- [x] 캔버스 확대/축소를 `Alt + 마우스 휠`이 아니라 마우스 휠만으로 할 수 있다.

## 9. v1.3.2 편집 사용성 개선

- [x] 텍스트 컴포넌트는 캔버스와 생성 HTML에서 가운데 정렬된다.
- [x] 텍스트 컴포넌트의 글자 크기를 조절할 수 있다.
- [x] 숫자 입력 중 최소값 보정 때문에 입력이 고정되지 않는다.
- [x] 입력창 라벨 표시 여부를 선택할 수 있다.
- [x] 꾸미기용 `divBox` 컴포넌트를 추가할 수 있다.

## 10. v1.4 캔버스 중심 작업 흐름

- [ ] 왼쪽 사이드바를 제거한다.
- [ ] 저장, 불러오기, 코드 복사, 화면 크기 선택을 상단바로 이동한다.
- [ ] 빈 캔버스 우클릭으로 컴포넌트를 생성할 수 있다.
- [ ] 컴포넌트 우클릭 메뉴에서 복사/붙여넣기를 할 수 있다.
- [ ] `Ctrl+C`, `Ctrl+V`로 선택 컴포넌트를 복사/붙여넣기할 수 있다.
- [ ] Shift + 클릭으로 다중 선택을 추가/해제할 수 있다.
- [ ] 컴포넌트 우클릭 메뉴에서 고정/고정 해제를 할 수 있다.
- [ ] 고정된 컴포넌트는 캔버스에서 선택/수정되지 않는다.
- [ ] 작업 패널에서 고정된 컴포넌트를 관리하고 해제할 수 있다.
- [ ] 작업 패널에서 기준 스타일을 관리할 수 있다.
