# v1 체크리스트

이 문서는 v1 구현 전에 확인할 항목과 기능별 완료 기준을 정리한다.

아직 최종 확정 문서가 아니라, 기획을 진행하면서 수정하는 작업용 체크리스트다.

## 1. 기획 확정 전 체크리스트

- [ ] v1 목표를 확정한다.
- [ ] v1에서 꼭 할 기능과 나중에 할 기능을 나눈다.
- [ ] 캔버스 이동 / 줌 기능의 조작 방식을 확정한다.
- [ ] 화면 크기 프리셋 목록을 확정한다.
- [ ] 컨테이너 내부 좌표 저장 방식을 확정한다.
- [ ] 그라데이션 데이터 구조를 확정한다.
- [ ] 애니메이션 이벤트와 효과 범위를 확정한다.
- [ ] Ollama 연동을 v1에 포함할지 결정한다.
- [ ] DB 저장을 v1에 포함할지 결정한다.

## 2. 캔버스 이동 / 줌 기능

- [ ] 캔버스 viewport 상태를 만든다.
- [ ] `Ctrl + 마우스휠`로 줌인 / 줌아웃할 수 있다.
- [ ] 줌은 마우스 위치를 기준으로 동작한다.
- [ ] 일반 `마우스휠`로 상하 이동할 수 있다.
- [ ] `Shift + 마우스휠`로 좌우 이동할 수 있다.
- [ ] `Space + 마우스 드래그`로 캔버스를 이동할 수 있다.
- [ ] 줌 최소값과 최대값을 제한한다.
- [ ] 선택, 드래그, 리사이즈 동작과 충돌하지 않는다.

## 3. 화면 크기 지정

- [ ] 캔버스 크기 프리셋을 정의한다.
- [ ] 16인치 화면 프리셋을 제공한다.
- [ ] 14인치 화면 프리셋을 제공한다.
- [ ] 모바일 프리셋을 제공한다.
- [ ] 태블릿 프리셋을 제공한다.
- [ ] 커스텀 사이즈를 입력할 수 있다.
- [ ] 선택한 화면 크기가 캔버스에 반영된다.
- [ ] 선택한 화면 크기가 저장/불러오기 데이터에 반영된다.

## 4. 영역 안에 요소 넣기

- [ ] 컨테이너 컴포넌트를 추가할 수 있다.
- [ ] 컨테이너를 선택할 수 있다.
- [ ] 컨테이너를 우클릭하면 요소 추가 메뉴가 열린다.
- [ ] 우클릭 메뉴에서 버튼을 추가할 수 있다.
- [ ] 우클릭 메뉴에서 텍스트를 추가할 수 있다.
- [ ] 우클릭 메뉴에서 input을 추가할 수 있다.
- [ ] 우클릭 메뉴에서 이미지를 추가할 수 있다.
- [ ] 추가된 요소는 컨테이너 내부 요소로 저장된다.
- [ ] 컨테이너 이동 시 내부 요소가 함께 이동한다.
- [ ] HTML 코드 생성 결과가 중첩 구조로 나온다.
- [ ] JSON 내보내기와 불러오기에서 부모-자식 관계가 유지된다.

## 5. 그라데이션 기능

- [ ] 스타일에 단일 색상과 그라데이션 모드를 구분한다.
- [ ] 배경색에 그라데이션을 적용할 수 있다.
- [ ] 버튼색에 그라데이션을 적용할 수 있다.
- [ ] 영역 배경에 그라데이션을 적용할 수 있다.
- [ ] 방향을 설정할 수 있다.
- [ ] 시작 색상을 설정할 수 있다.
- [ ] 끝 색상을 설정할 수 있다.
- [ ] 코드 생성 결과에 CSS gradient가 반영된다.
- [ ] 저장/불러오기에서 그라데이션 설정이 유지된다.

## 6. 애니메이션 기능

- [ ] 요소별 이벤트를 설정할 수 있다.
- [ ] hover 이벤트를 지원한다.
- [ ] 클릭 이벤트를 지원한다.
- [ ] 페이지 진입 이벤트를 지원한다.
- [ ] 지정 위치로 이동하는 애니메이션을 설정할 수 있다.
- [ ] 색상 변경 애니메이션을 설정할 수 있다.
- [ ] 사라지기 또는 날아가기 애니메이션을 설정할 수 있다.
- [ ] 크기 변경 애니메이션을 설정할 수 있다.
- [ ] 투명도 변경 애니메이션을 설정할 수 있다.
- [ ] duration과 easing을 설정할 수 있다.
- [ ] 저장/불러오기에서 애니메이션 설정이 유지된다.

## 7. v1 완료 기준 초안

- [ ] 화면 크기를 정하고 그 안에서 UI를 설계할 수 있다.
- [ ] 캔버스를 확대/축소하고 이동할 수 있다.
- [ ] 컨테이너 안에 요소를 넣을 수 있다.
- [ ] 컨테이너 이동 시 내부 요소가 함께 움직인다.
- [ ] 주요 스타일에 그라데이션을 줄 수 있다.
- [ ] 요소별 이벤트와 애니메이션 설정을 저장할 수 있다.
- [ ] 생성된 HTML/CSS 코드가 현재 UI 데이터와 일치한다.
- [ ] JSON 내보내기와 불러오기가 v1 데이터 구조를 유지한다.
