# v1 체크리스트

이 문서는 v1 구현 전에 확인할 항목과 기능별 완료 기준을 정리한다.

아직 최종 확정 문서가 아니라, 기획을 진행하면서 수정하는 작업용 체크리스트다.

## 1. 기획 확정 전 체크리스트

- [x] v1 목표를 확정한다.
- [x] v1에서 꼭 할 기능과 나중에 할 기능을 나눈다.
- [x] 캔버스 이동 / 줌 기능의 조작 방식을 확정한다.
- [x] 화면 크기 프리셋 목록을 확정한다.
- [x] 컨테이너 내부 좌표 저장 방식을 확정한다.
- [x] 그라데이션 데이터 구조를 확정한다.
- [x] 애니메이션 이벤트와 효과 범위를 확정한다.
- [x] Ollama 연동을 v1에 포함할지 결정한다.
- [x] DB 저장을 v1에 포함할지 결정한다.

결정 내용:

- 컨테이너 내부 요소의 좌표는 부모 컨테이너 기준으로 저장한다.
- 캔버스 이동 / 줌 상태는 `project.canvas.viewport`에 저장한다.
- 그라데이션은 `style.background` 안에서 단색과 그라데이션을 구분한다.
- 애니메이션은 요소별 `interactions` 배열에 저장한다.
- Ollama와 DB 저장은 v1 필수 구현에서 제외하고, project schema 확장 여지만 둔다.

## 2. 캔버스 이동 / 줌 기능

- [x] 캔버스 viewport 상태를 만든다.
- [x] `Ctrl + 마우스휠`로 줌인 / 줌아웃할 수 있다.
- [x] 줌은 마우스 위치를 기준으로 동작한다.
- [x] 일반 `마우스휠`로 상하 이동할 수 있다.
- [x] `Shift + 마우스휠`로 좌우 이동할 수 있다.
- [x] `Space + 마우스 드래그`로 캔버스를 이동할 수 있다.
- [x] 줌 최소값과 최대값을 제한한다.
- [x] 선택, 드래그, 리사이즈 동작과 충돌하지 않는다.

## 3. 화면 크기 지정

- [x] 캔버스 크기 프리셋을 정의한다.
- [x] 16인치 화면 프리셋을 제공한다.
- [x] 14인치 화면 프리셋을 제공한다.
- [x] 모바일 프리셋을 제공한다.
- [x] 태블릿 프리셋을 제공한다.
- [x] 커스텀 사이즈를 입력할 수 있다.
- [x] 선택한 화면 크기가 캔버스에 반영된다.
- [x] 선택한 화면 크기가 저장/불러오기 데이터에 반영된다.
