## v1.3 구현 기준

v1.3 계열에서는 다음 항목이 구현 기준이다.

- 박스 제거와 컨테이너 중심 구조 전환
- 기존 `box` 저장 데이터의 `container` 변환
- 컨테이너 안에 컨테이너 추가
- 캔버스 애니메이션 미리보기
- 도킹 작업 패널과 조정/꾸미기/애니메이션/HTML 탭
- 작업 패널 위치, 크기, 도킹 상태를 workspace settings에 저장
- 그라데이션 기준점, 그림자, border, 모서리, 투명도 편집
- 생성 HTML에 v1.3 스타일과 애니메이션 반영
- v1.3.1 컨테이너 내부 드래그, 작업 패널 떼기, 마우스 휠 줌 버그 수정
- v1.3.2 텍스트 정렬/크기, 숫자 입력, 입력창 라벨 선택, 꾸미기용 div 박스 개선

## v1.4 기획 기준

v1.4에서는 캔버스 중심 작업 흐름으로 구조를 가볍게 정리한다.

- 왼쪽 사이드바 제거
- 저장, 불러오기, 코드 복사, 화면 크기 선택을 상단바로 이동
- 컴포넌트 추가는 캔버스 우클릭 중심으로 전환
- 컴포넌트 복사/붙여넣기 추가
- Shift + 클릭 다중 선택 편의성 개선
- 컴포넌트 고정 기능 추가
- 작업 패널에 잠금 관리 탭 추가
- 작업 패널에 기준 스타일 탭 추가
