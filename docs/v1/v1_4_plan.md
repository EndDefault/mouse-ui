# v1.4 기획안

## 목표

`v1.4`의 목표는 `mouse-ui`를 컴포넌트 추가 중심 UI에서 캔버스 중심 작업 도구로 정리하는 것이다.

왼쪽 사이드바는 제거하고, 컴포넌트 생성은 캔버스 우클릭을 기본 흐름으로 둔다. 저장, 불러오기, 코드 복사, 화면 크기 선택 같은 전역 작업은 상단바로 옮기고, 잠금 컴포넌트 관리와 기준 스타일 관리는 작업 패널 탭으로 통합한다.

이번 버전은 많은 기능을 한꺼번에 확장하기보다, 작업 흐름을 가볍게 만들고 이후 꾸미기/애니메이션 확장을 붙이기 좋은 구조를 만드는 데 집중한다.

## 핵심 방향

- 왼쪽 사이드바 제거
- 캔버스 작업 영역 확대
- 컴포넌트 추가는 캔버스 우클릭 중심으로 전환
- 저장, 불러오기, 코드 복사, 화면 크기 선택은 상단바로 이동
- 작업 패널에 잠금 관리 탭 추가
- 작업 패널에 기준 스타일 탭 추가
- 컴포넌트 고정 기능 추가
- 컴포넌트 복사/붙여넣기 추가
- Shift + 클릭 기반 다중 선택 편의성 개선

## 하지 않는 것

이번 작전 변경으로 아래 기능은 `v1.4` 범위에서 제외하거나 보류한다.

- 왼쪽 프레임/레이어 사이드바
- 프레임 그룹 패널
- 그룹 접기/펼치기
- 레이어 드래그 정렬
- 별도 그룹 관리 UI

컴포넌트 복사/붙여넣기와 다중 선택 이동이 있으면 초기 단계에서는 별도 프레임 그룹 기능 없이도 충분히 작업 흐름을 만들 수 있다고 본다.

## 1. 왼쪽 사이드바 제거

기존 왼쪽 사이드바의 역할을 줄이고, 캔버스 공간을 넓힌다.

기존 역할:

- 컴포넌트 추가
- 저장/불러오기
- 화면 크기 설정

변경 후:

- 컴포넌트 추가는 캔버스 우클릭 메뉴에서 처리한다.
- 저장/불러오기/코드 복사는 상단바에서 처리한다.
- 화면 크기 선택은 상단바 버튼 영역에서 처리한다.
- 왼쪽 사이드바는 제거한다.

## 2. 상단바 재구성

상단바는 프로젝트 전체 작업을 담당한다.

상단바 항목:

- 저장
- 불러오기
- JSON 내보내기
- 코드 복사
- 미리보기
- 화면 크기 버튼

화면 크기 버튼 예시:

- Desktop
- Tablet
- Mobile
- Custom

기존 캔버스 크기 초기화 버튼은 우선 만들지 않는다. 대신 화면 크기 버튼을 눌러 원하는 캔버스 기준을 빠르게 바꾸는 방향으로 간다.

## 3. 캔버스 우클릭 생성

캔버스 빈 영역을 우클릭하면 해당 위치에 컴포넌트를 생성할 수 있게 한다.

우클릭 메뉴 예시:

- 버튼 추가
- 텍스트 추가
- 입력창 추가
- 이미지 추가
- 컨테이너 추가
- div 박스 추가

규칙:

- 빈 캔버스 우클릭은 최상위 컴포넌트를 생성한다.
- 컨테이너 우클릭은 해당 컨테이너 내부에 컴포넌트를 생성한다.
- 생성 좌표는 우클릭한 위치 기준으로 잡는다.

## 4. 컴포넌트 복사/붙여넣기

컴포넌트 복사 기능을 추가한다.

기능:

- 선택 컴포넌트 복사
- 붙여넣기 시 오른쪽 아래로 약간 이동해서 생성
- 컨테이너 안 컴포넌트는 parentId 관계를 유지해 복사
- 우클릭 메뉴에 복사/붙여넣기 추가
- `Ctrl+C`, `Ctrl+V` 지원

다중 선택 상태에서는 선택된 컴포넌트들을 함께 복사한다.

## 5. Shift + 클릭 다중 선택

다중 선택 편의성을 강화한다.

기능:

- Shift + 클릭으로 선택 목록에 컴포넌트를 추가한다.
- 이미 선택된 컴포넌트를 Shift + 클릭하면 선택 상태를 유지한다.
- 다중 선택한 컴포넌트는 함께 이동할 수 있다.
- 기존 드래그 박스 다중 선택은 유지한다.

별도 그룹 기능을 만들기 전까지, Shift + 클릭과 드래그 다중 선택을 그룹 작업의 기본 편의 기능으로 사용한다.

## 6. 컴포넌트 고정 기능

컴포넌트 우클릭 메뉴에 고정 기능을 추가한다.

기능:

- 컴포넌트 고정
- 고정 해제
- 고정된 컴포넌트는 캔버스에서 선택되지 않는다.
- 고정된 컴포넌트는 이동/리사이즈/속성 수정이 불가능하다.
- 고정 상태는 project JSON에 저장한다.

데이터 예시:

```js
{
  id: "button-1",
  type: "button",
  locked: true
}
```

고정된 컴포넌트는 작업 패널의 잠금 관리 탭에서 다시 풀 수 있게 한다.

## 7. 작업 패널 잠금 관리 탭

작업 패널에 잠금 관리 탭을 추가한다.

탭 이름 후보:

- 잠금
- 고정 관리
- 잠금 관리

기능:

- 고정된 컴포넌트 목록 표시
- 컴포넌트 이름/id 표시
- 고정 해제 버튼
- 전체 고정 해제

이 탭은 캔버스에서 선택할 수 없는 컴포넌트를 다시 관리하기 위한 안전 장치다.

## 8. 작업 패널 기준 스타일 탭

기준 스타일 기능은 작업 패널 카테고리로 추가한다.

탭 이름 후보:

- 기준
- 기준 스타일
- 테마

처음에는 새로 생성되는 컴포넌트의 기본값을 정하는 데 집중한다.

관리 항목:

- 기본 색상
- 버튼 기본 스타일
- 텍스트 기본 스타일
- 입력창 기본 스타일
- 컨테이너 기본 스타일
- div 박스 기본 스타일

동작 방식:

1. 사용자가 기준 스타일을 설정한다.
2. 이후 새로 생성되는 컴포넌트에 기준 스타일을 자동 적용한다.
3. 선택 컴포넌트에 기준 적용 버튼을 제공한다.
4. 기준 초기화 버튼을 제공한다.

기준 스타일은 project JSON에 넣을지 workspace settings에 둘지 구현 전에 결정한다. 생성 결과와 함께 공유되어야 한다면 project JSON, 개인 작업 환경 기본값이면 workspace settings가 더 적합하다.

## 9. 꾸미기와 애니메이션 확장 방향

`v1.4`의 주 작업은 구조 변경이지만, 이후 확장을 위해 아래 방향을 유지한다.

꾸미기 확장 후보:

- 배경 이미지
- 블러 배경
- border 위치별 설정
- radius 프리셋
- 그림자 프리셋
- 텍스트 굵기, 줄 간격, 자간, 정렬
- 버튼 variant
- 상태별 스타일

애니메이션 확장 후보:

- fade in/out
- slide in/out
- bounce
- pulse
- shake
- float
- rotate
- zoom in/out
- hover lift

꾸미기와 애니메이션 확장은 프리셋 중심으로 늘리고, 필요한 경우에만 고급 수치 편집을 제공한다.

## 우선순위

1. 왼쪽 사이드바 제거와 상단바 재구성
2. 빈 캔버스 우클릭 생성
3. 컴포넌트 복사/붙여넣기
4. Shift + 클릭 다중 선택
5. 컴포넌트 고정
6. 작업 패널 잠금 관리 탭
7. 작업 패널 기준 스타일 탭

## 완료 기준

- 왼쪽 사이드바 없이 캔버스 중심으로 작업할 수 있다.
- 컴포넌트를 캔버스 우클릭으로 생성할 수 있다.
- 저장, 불러오기, 코드 복사, 화면 크기 선택을 상단바에서 사용할 수 있다.
- 선택 컴포넌트를 복사/붙여넣기할 수 있다.
- Shift + 클릭으로 다중 선택을 조정할 수 있다.
- 컴포넌트를 고정하면 캔버스에서 선택/수정되지 않는다.
- 작업 패널에서 고정된 컴포넌트를 해제할 수 있다.
- 작업 패널에서 기준 스타일을 관리할 수 있다.
