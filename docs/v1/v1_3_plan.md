# v1.3 기획안

## 목표

`v1.3`의 목표는 UI 빌더를 단순 배치 도구에서 더 실제적인 화면 설계 도구로 발전시키는 것이다.

이번 버전에서는 요소 구조를 컨테이너 중심으로 정리하고, 애니메이션을 캔버스에서 직접 확인할 수 있게 하며, 오른쪽 사이드바를 자유롭게 움직이는 작업 패널로 바꾼다. 또한 꾸미기 기능을 확장해 그라데이션, 그림자, 모서리, border 같은 시각 스타일을 더 세밀하게 조정할 수 있게 한다.

## 핵심 방향

- 박스 제거와 컨테이너 중심 구조
- 컨테이너 안에 컨테이너 추가
- 애니메이션 미리보기
- 오른쪽 사이드바를 플로팅 작업 패널로 전환
- 조정 / 꾸미기 / 애니메이션 / HTML 탭 구성
- 그라데이션, 그림자, border, 모서리 꾸미기 확장

## 1. 박스 제거와 컨테이너 중첩

기존 `박스`는 컨테이너와 역할이 겹치므로 제거한다.

앞으로 사각형 영역, 섹션, 카드, 폼 영역, 그룹은 모두 `컨테이너`로 표현한다.

### 기능

- 툴바에서 박스 추가 제거
- 컨테이너 추가 유지
- 컨테이너 우클릭 메뉴에 `컨테이너 추가` 추가
- 컨테이너 안에 버튼, 텍스트, input, 이미지, 컨테이너 추가 가능
- 컨테이너 이동 시 내부 요소가 함께 이동
- HTML 생성 시 중첩된 `<div>` 구조로 출력

### 기존 데이터 처리

기존 저장 데이터에 `box`가 있을 수 있으므로 바로 삭제하지 않고, 불러올 때 `container`로 변환한다.

```txt
box -> container
```

## 2. 애니메이션 미리보기

현재 애니메이션은 설정과 HTML/CSS 생성 중심이다. v1.3에서는 캔버스에서 애니메이션을 직접 확인할 수 있게 한다.

### 기능

- hover 애니메이션 캔버스 미리보기
- 클릭 애니메이션 캔버스 미리보기
- 페이지 진입 애니메이션 재생 버튼
- 상태 변경 애니메이션 미리보기 토글
- 드래그/리사이즈와 애니메이션 충돌 방지

### 방향

편집 중에는 요소 이동이 우선이고, 애니메이션 확인은 미리보기 상태나 재생 버튼을 통해 확인한다.

## 3. 플로팅 작업 패널

오른쪽 고정 사이드바를 화면 위에 떠 있는 작업 패널로 전환한다.

이 패널은 사용자가 원하는 위치로 드래그해서 옮길 수 있고, 필요하면 다시 오른쪽에 붙일 수 있다.

### 이름

- 문서상 이름: `도킹 작업 패널`
- UI 표시 이름: `작업 패널`

### 탭 구성

- 조정
- 꾸미기
- 애니메이션
- HTML

### 기능

- 패널 드래그 이동
- 패널 크기 조절
- 오른쪽에 붙이기
- 화면에서 떼기
- 마지막 위치 저장
- 레이아웃 초기화

### 저장 기준

프로젝트 데이터와 작업 환경 데이터는 분리한다.

```txt
project JSON:
  사용자가 만든 UI 데이터

workspace settings:
  패널 위치, 크기, 열린 탭, 도킹 여부
```

### 적용 대상

- 텍스트
- input
- 이미지 영역

### 기능

- 배경색
- 글자색
- 그라데이션
- 그림자
- 모서리 둥글기
- border 색상
- border 두께
- border 스타일
- 투명도

## 5. 그라데이션 확장

기존 그라데이션은 시작 색상과 끝 색상을 정하는 수준이었다. v1.3에서는 그라데이션 기준점을 조정할 수 있게 한다.

### 기능

- 선형 그라데이션
- 방향 설정
- 시작 색상
- 끝 색상
- 시작 위치
- 끝 위치
- 기준점 이동 UI

### 예시 데이터

```js
background: {
  type: "gradient",
  gradient: {
    kind: "linear",
    direction: "to right",
    from: "#2563eb",
    to: "#14b8a6",
    fromPosition: 0,
    toPosition: 100
  }
}
```
