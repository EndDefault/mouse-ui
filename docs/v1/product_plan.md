# v1 전체 기획안

## 목표

현재 UI 제작 기능을 확장해서, 단순히 요소를 배치하는 수준을 넘어 실제 화면 설계 도구처럼 사용할 수 있게 만든다.

핵심 방향은 아래와 같다.

- 영역 구성
- 반응형 작업 환경
- 스타일 확장
- 애니메이션
- 캔버스 조작 편의성

## 기능 방향

### 1. 영역 안에 요소 넣기

`div` 같은 영역/컨테이너를 만들 수 있게 한다.

생성한 영역을 우클릭하면 요소 추가 메뉴를 제공한다.

예시 메뉴:

- 버튼 추가
- 텍스트 추가
- input 추가
- 이미지 추가
- 기타 UI 요소 추가

추가된 요소는 해당 영역 내부에 포함되며, 영역 이동 시 함께 움직이도록 한다.

### 2. 화면 크기 지정

작업할 캔버스 크기를 미리 선택할 수 있게 한다.

예시:

- 16인치 화면
- 14인치 화면
- 모바일
- 태블릿
- 커스텀 사이즈

선택한 화면 크기에 맞춰 캔버스가 생성되고, 그 안에서 UI를 설계할 수 있게 한다.

### 3. 애니메이션 기능

특정 이벤트에 따라 요소에 애니메이션을 줄 수 있게 한다.

이벤트 예시:

- hover
- 클릭
- 페이지 진입
- 특정 상태 변경

애니메이션 예시:

- 지정 위치로 이동
- 색상 변경
- 날아가기 / 사라지기
- 크기 변경
- 투명도 변경

각 요소별로 이벤트와 애니메이션을 연결할 수 있는 설정 UI가 필요하다.

### 4. 그라데이션 기능

단일 색상만으로는 디자인이 단조로울 수 있으므로 그라데이션 옵션을 추가한다.

적용 대상:

- 배경색
- 버튼색
- 영역 배경

설정 항목:

- 방향
- 시작 색상
- 끝 색상

### 5. 캔버스 화면 이동 및 확대/축소

작업 공간을 더 편하게 탐색할 수 있도록 캔버스 조작 기능을 추가한다.

조작 방식:

- 캔버스 위 `마우스휠`: 줌인 / 줌아웃
- 좌우 패널 위 `마우스휠`: 해당 패널만 세로 스크롤
- `Space`: 누른 상태에서 마우스를 움직이면 캔버스 이동
- 객체 우클릭: 삭제 메뉴 제공
- 빈 캔버스 드래그: 여러 객체 선택

선택된 객체는 캔버스에서 테두리로 표시하고, HTML 코드 패널에서도 해당 객체 라인을 강조한다.

## 우선순위 초안

| 순서 | 기능 | 이유 |
| --- | --- | --- |
| 1 | 캔버스 이동 / 줌 기능 | 화면 설계 도구의 기본 작업감을 먼저 만든다. |
| 2 | 화면 크기 지정 | 반응형 작업 기준을 먼저 정한다. |
| 3 | 영역 안에 요소 넣기 | 실제 화면 구조를 만들 수 있게 한다. |
| 4 | 그라데이션 | 스타일 표현력을 넓힌다. |
| 5 | 애니메이션 기능 | 상호작용 표현을 확장한다. |

## v1에서 먼저 결정할 것

- 영역 내부 좌표를 부모 기준으로 저장할지, 전체 캔버스 기준으로 저장할지 결정한다.
- 캔버스 확대/이동 상태를 프로젝트에 저장할지, 작업 환경 상태로만 둘지 결정한다.
- 그라데이션과 애니메이션을 기존 `style`에 넣을지 별도 속성으로 분리할지 결정한다.
- Ollama가 생성하거나 수정할 수 있는 데이터 범위를 어디까지 허용할지 결정한다.
- DB 저장을 v1 범위에 포함할지, localStorage/JSON 이후 단계로 둘지 결정한다.

## v1 성공 기준 초안

- 사용자가 화면 크기를 정하고 캔버스를 확대/이동하며 작업할 수 있다.
- 사용자가 컨테이너를 만들고 그 안에 요소를 추가할 수 있다.
- 컨테이너를 이동하면 내부 요소가 함께 이동한다.
- 주요 요소에 그라데이션 스타일을 줄 수 있다.
- 요소별 이벤트와 애니메이션 설정을 저장 가능한 데이터로 표현할 수 있다.
- 데이터 구조가 이후 Ollama와 DB 저장으로 확장될 수 있다.
