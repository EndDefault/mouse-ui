# v0 문서 안내

이 폴더는 `mouse-ui`의 초기 MVP인 `v0.5.0`까지 사용한 기획, 개발 기준, 체크리스트, 작업 기록을 보관한다.

`v0`는 기능 가능성을 확인한 첫 저장 가능한 기준점이다. 현재 작업 기준은 `v1` 문서로 넘어갔지만, 초기 구현 맥락을 추적할 수 있도록 v0 전용 문서를 이 폴더에 모아둔다.

## 문서 목록

- [v0 제품 기획서](product_plan.md): 초기 Visual UI Code Builder의 목표와 MVP 범위
- [v0 개발 방향 및 규칙](development_rules.md): 초기 상태, 데이터, UI, 코드 생성 기준
- [v0 파일 구조 및 분리 규칙](file_structure_rules.md): 초기 builder 폴더 구조와 책임 분리 기준
- [v0 버전 관리 및 체크리스트](version_checklist.md): `v0.1.0`부터 `v0.5.0`까지의 진행 상태
- [v0 작업 기록](history.md): 완료된 v0 버전별 작업 기록

## 운영 기준

- 앞으로 할 일은 v0 문서가 아니라 `docs/v1/`과 공통 운영 문서에서 관리한다.
- v0 문서는 이미 끝난 작업의 맥락을 보관한다.
- v0 문서를 수정할 때는 현재 구현 기준을 덮어쓰기보다 당시 기준과 완료 기록을 보존한다.
