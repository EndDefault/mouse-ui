# v0 작업 기록

`v0`는 `mouse-ui`가 실제로 만들 수 있는지 확인한 실험과 기초 구현 단계다.

이 단계에서는 완성도 높은 구조보다 빠르게 핵심 흐름을 만드는 것을 우선했다. 사용자가 컴포넌트를 추가하고, 캔버스에서 선택하고, 속성을 바꾸고, HTML 코드를 보고, 작업 내용을 저장하고 불러오는 최소 흐름을 확인했다.

## v0의 목적

- 마우스로 UI를 배치하는 기본 경험을 만든다.
- UI를 문자열이 아니라 `components` 데이터로 관리한다.
- 캔버스 미리보기와 HTML 코드 생성을 같은 데이터에서 만든다.
- 저장 가능한 기준점을 만든 뒤, `v1.0.0`에서 구조와 사용성을 다시 정리한다.

## 버전별 작업

### v0.1.0

기본 React/Vite 프로젝트와 UI 빌더의 뼈대를 만들었다.

- 상단 메뉴, 왼쪽 사이드바, 중앙 캔버스, 오른쪽 코드 패널 구조를 만들었다.
- `components`와 `selectedId` 상태를 만들었다.
- 버튼 컴포넌트 추가와 선택 흐름을 만들었다.
- `components` 데이터에서 HTML 코드를 생성하는 기본 `generateHtml` 흐름을 만들었다.
- `src/features/builder` 중심의 폴더 구조를 잡았다.

### v0.2.0

캔버스 위 요소를 마우스로 움직이고 크기를 바꿀 수 있게 만들었다.

- `react-rnd`를 사용해 드래그 이동을 추가했다.
- 캔버스 요소의 `x`, `y` 위치를 상태에 저장했다.
- 리사이즈로 `width`, `height` 값을 바꿀 수 있게 했다.
- 위치와 크기 변경이 캔버스와 코드 패널에 반영되게 했다.

### v0.3.0

선택한 요소의 속성을 오른쪽 패널에서 수정할 수 있게 만들었다.

- 선택된 요소 정보를 Inspector에 표시했다.
- 텍스트, 위치, 크기, 배경색, 글자색, 둥근 정도를 수정할 수 있게 했다.
- Inspector 변경이 캔버스와 생성 코드에 바로 반영되게 했다.

### v0.4.0

버튼 외의 기본 컴포넌트를 추가했다.

- 텍스트 컴포넌트를 추가했다.
- 입력창 컴포넌트를 추가했다.
- 박스 컴포넌트를 추가했다.
- 각 컴포넌트의 기본 데이터, 캔버스 렌더링, HTML 코드 생성을 연결했다.
- 카드 컴포넌트는 v0 범위에서 제외하고, 이후 구조 정리 뒤 다시 검토하기로 했다.

### v0.5.0

작업 내용을 저장하고 다시 가져올 수 있는 기준점을 만들었다.

- HTML 코드 복사 버튼을 추가했다.
- 복사 성공과 실패 상태를 버튼에 표시했다.
- localStorage 자동 저장을 추가했다.
- 새로고침 뒤 이전 작업을 복원할 수 있게 했다.
- JSON 내보내기를 추가했다.
- JSON 불러오기를 추가했다.
- docs 구조와 `v1.0.0` 전환 흐름을 정리했다.

## v0에서 확인한 문제

- 버전마다 PR과 문서를 촘촘히 관리하는 방식은 개발 속도를 떨어뜨렸다.
- 컴포넌트 정의, 캔버스 렌더링, Inspector, codegen이 아직 하나의 기준으로 묶여 있지 않다.
- 컴포넌트가 늘어날수록 수정해야 하는 파일이 많아질 가능성이 보인다.
- 우클릭 메뉴, 삭제, 복제처럼 실제 편집에 필요한 기능이 아직 부족하다.
- 빈 캔버스 상태, 선택되지 않은 상태, 좁은 화면 대응 같은 사용성 정리가 필요하다.
- 저장과 JSON 불러오기 흐름은 생겼지만, 데이터 검증과 복구 경험은 더 안정화해야 한다.

## v1로 넘길 항목

- 컴포넌트 정의를 한 곳에서 관리할지 결정한다.
- Inspector 필드 표시 방식을 컴포넌트 정의와 연결한다.
- codegen 구조를 컴포넌트별로 분리할지 결정한다.
- 우클릭 메뉴를 추가한다.
- 삭제와 복제를 추가한다.
- 선택 상태와 빈 상태 UI를 정리한다.
- 저장된 프로젝트와 JSON 불러오기 흐름을 안정화한다.
- README와 docs 구조를 새 개발 방식에 맞게 유지한다.

## 정리

`v0`는 폐기할 코드가 아니라 첫 번째 기준점이다.

다만 이 흐름을 그대로 `v0.6.0`으로 이어가기보다, `main`에 저장 가능한 상태로 남긴 뒤 `v1.0.0`에서 구조와 사용성을 새 기준으로 정리한다.
