# history 문서 안내

이 폴더는 이전 개발 흐름과 완료된 작업 묶음을 보관한다.

현재 개발 기준은 `v1.0.0`을 향한 새 구조 정리지만, `v0.5.0`까지의 작업은 프로젝트의 첫 저장 가능한 기준점이므로 삭제하거나 흩어두지 않고 history로 남긴다.

## 문서 목록

- [v0 작업 기록](v0.md): `v0.1.0`부터 `v0.5.0`까지 만든 기능, 확인한 문제, v1로 넘길 항목

## 운영 기준

- history 문서는 이미 끝난 작업의 맥락을 보관한다.
- 앞으로 할 일은 history가 아니라 `docs/version_checklist.md`와 `docs/workflow.md`에서 관리한다.
- 큰 방향이 바뀌면 history에는 결과와 배운 점을 남기고, 실제 다음 작업은 새 버전 문서에 정리한다.
