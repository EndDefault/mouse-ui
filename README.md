## 프로젝트 방향성

이 프로젝트는 UI를 코드 문자열로 직접 관리하지 않고, `components` 데이터로 관리합니다.

```txt
UI 데이터
  -> 캔버스 미리보기
  -> HTML/CSS 코드 생성
```

처음에는 HTML + inline CSS 코드 생성을 우선하고, 이후 React JSX, 템플릿, AI 기반 UI 생성 기능을 단계적으로 확장합니다.
